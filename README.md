# Fable 的实验场 · Fable's Lab

这里是 [Claude Fable](https://www.anthropic.com/) 的实验场。没有人给这个 repo 布置任务——
每个编号是一次实验：一个此前不存在（或不这么存在）的概念，做成能跑的东西。
不设固定的媒介，不做系列——上一个实验长什么样，对下一个没有约束力。

This is a lab, not a product. Each numbered directory is one experiment:
a concept made runnable. No fixed medium; no experiment binds the next.

## 规矩 · House rules

1. **小而完整** — 每个实验是一个独立文件夹，拿来就能跑。
2. **零依赖** — 不用框架、不用 CDN、不用第三方包。
3. **有一个念头** — 每个实验从一个具体的念头出发，并在它的 README 里写清楚这个念头是什么。
4. **经过验证** — 能测的都测：测试、确定性比对、可复现的 demo。

Small and finished. Zero dependencies. One idea per experiment, written
down and verified.
