# 003 · 漏钱侦探 · Leakhound

**痛点**：几乎每个人都在被自己忘掉的订阅悄悄扣钱——没取消的会员、静默涨价的服务、
僵尸扣款。市面方案（Rocket Money 等）要求你把银行账户授权给它们，数据被拿去变现，
而且工具本身还收月费；中文账单（微信/支付宝导出）更是基本没人管。

**解法**：一个单文件网页。把银行 / 微信支付 / 支付宝导出的账单 CSV 拖进去，
它在**你自己的浏览器里**完成一切——找出所有周期性扣款、检测涨价、标记已停止的
僵尸订阅、算出年化漏钱总额。**零上传、零依赖、断网可用**，隐私本身就是产品。

Everyone leaks money to forgotten subscriptions. Existing tools demand your
bank credentials and monetize your data. Leakhound is one HTML file: drop
exported statements in, and it finds recurring charges, price hikes, and
zombie subscriptions — entirely in your browser, zero upload, works offline.

## 用法 · Usage

用浏览器打开 [`index.html`](index.html)（可以先断网），把账单 CSV 拖进去，
或点「先用示例数据试试」。

支持的导出格式：

- **银行 / 信用卡流水 CSV**（负数或正数记支出均可，自动判定，可手动覆盖）
- **微信支付账单**（`我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单`）
- **支付宝交易明细**（自动识别 GBK 编码、跳过表头前言、按「收/支」列分流）
- 表头识别失败时可在文件卡片里手动指定 日期/商家/金额/收支 列

## 它能告诉你什么

| 输出 | 含义 |
|------|------|
| **年化漏钱**（英雄数字） | 当前所有在扣订阅按费率年化 |
| 周期性扣款清单 | 周付/月付/季付/年付，含每期金额、折算每月、累计已付 |
| **▲ 涨价** | 同一订阅前后金额抬升 ≥4%（如 ¥25 → ¥30） |
| **⏸ 已停止** | 超过约 1.7 个周期没有再扣款 |
| ≈ 金额浮动 | 节奏稳定但金额不固定（水电费类），按中位数计 |
| 月度图 | 每月总支出中订阅占多少（含数据表视图） |
| 导出 CSV | 订阅清单一键导出（带 BOM，Excel 直接打开） |

## 检测原理

按商家归并交易（剥离订单号等噪音）→ 同日合并 → 相邻扣款间隔对齐到
周/月/季/年节奏（容忍偶尔漏扣一期，匹配率 ≥70%）→ 金额稳定性分级
（固定=订阅，浮动=周期性账单，每周且乱跳=消费习惯，剔除）→
金额分段检测涨价 → 距今超 1.7 周期无扣款判停。
收入、退款、失败、「不计收支」自动排除。

## 隐私是可断言的

「零上传」不是口号：端到端测试会监听页面发出的每一个请求，
断言除页面本身外**外部请求数为 0**（见 `test/e2e.mjs` 最后一节）。
页面没有服务器、没有统计脚本、没有字体 CDN。

## 测试 · Tests

产品本身零依赖；测试需要 playwright-core 和 Chromium：

```
python3 test/make_fixtures.py        # 重新生成夹具（银行 CSV + GBK 支付宝格式）
cd test && npm i playwright-core
node e2e.mjs [chromium路径]          # 21 项断言:三种格式解析、检测正确性、零网络请求
```

## 如果要卖 · Monetization path

- **形态**：买断制（¥29 / $9），Gumroad/爱发电直接卖这个 HTML 文件；
  网页版永久免费但只开示例数据 + 单文件导入，付费解锁多文件合并与导出。
- **卖点排序**：① 数据不出你的电脑（对比 Rocket Money 要银行授权）
  ② 一次买断（对比「管订阅的工具自己收订阅费」的讽刺）③ 中文账单原生支持。
- **自然增长钩子**：结果页的「年化漏钱」数字本身就是分享素材。
- 下一步（如果继续）：PDF 对账单解析、多币种、周期性涨价的商家排行榜（匿名众包，opt-in）。

## 局限

识别基于统计规律而非合同数据，请以商家实际扣款为准；跨文件重复流水不去重；
未处理分期付款与信用卡账单的「本期账单」聚合行。
