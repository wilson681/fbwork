检出的周期性扣款

它是怎么判断的？
  • 按商家归并交易，寻找周付 / 月付 / 季付 / 年付节奏（允许偶尔漏扣一期）。
  • 金额基本固定 → 订阅；金额有浮动但节奏稳定（如水电费）→ 标「金额浮动」。
  • 同一订阅前后金额抬升 ≥ 4% → 标「涨价」；超过约 1.7 个周期没再扣款 → 标「已停止」。
  • 收入、退款、失败与「不计收支」的交易已自动排除。
